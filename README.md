# Mohamed Portfolio

A personal frontend portfolio built with HTML, CSS and vanilla JavaScript.

## Featured work
- **Drum Kit** — interactive browser drum kit
- **Dice Challenge** — two-player dice game
- **Nexora Digital** — fictional digital-agency website concept
- **DevHub Dashboard** — API-powered user directory using JSONPlaceholder

The movie-ranking and birthday-invite pages are small HTML practice exercises.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.
